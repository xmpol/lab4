## Данные и подготовка

Использован `german.csv`: 1 000 наблюдений, 20 входных признаков и целевой столбец `Creditability`. Файл читается с разделителем `;`. Целевая переменная содержит два класса: 0 и 1; положительным считается класс 1. Все входные столбцы в данном файле представлены числовыми значениями (в том числе категориальные признаки, закодированные целыми числами). Пропущенных значений в исходном датасете не обнаружено.

Данные разделены на train/test в отношении 80/20 с помощью `train_test_split(test_size=0.20, random_state=42, stratify=y)`. Стратификация сохраняет соотношение классов. Для всех моделей используется только train-часть при обучении. В конвейер добавлен `SimpleImputer(strategy="median")`, чтобы обработка была устойчивой к возможным пропускам в новых данных; на исходном датасете фактической импутации не потребовалось. Для MLP дополнительно применён `StandardScaler`, поскольку нейронная сеть чувствительна к масштабу признаков. Для деревьев и ансамблей на деревьях масштабирование не применялось.

## Гипотезы и эксперименты

Проверялись следующие гипотезы:

1. Ансамбли деревьев способны описывать нелинейные зависимости и взаимодействия между признаками лучше, чем простая линейная граница.
2. Бэггинг (Random Forest и Extra Trees) должен уменьшать нестабильность отдельных деревьев.
3. Бустинг (Gradient Boosting и HistGradientBoosting) может повысить качество за счёт последовательного исправления ошибок предыдущих слабых моделей.
4. Полносвязная MLP может извлечь нелинейные зависимости, но на небольшом табличном наборе данных может переобучаться или требовать более тщательной настройки.

Сравнивались пять подходов:

- **Extra Trees:** 500 деревьев, `min_samples_leaf=2`, `max_features=0.8`, `class_weight="balanced"`.
- **Random Forest:** 500 деревьев, `min_samples_leaf=3`, `max_features="sqrt"`, `class_weight="balanced_subsample"`.
- **HistGradientBoosting:** 150 итераций, `learning_rate=0.06`, `max_leaf_nodes=15`, `l2_regularization=2.0`.
- **Gradient Boosting:** 150 оценщиков, `learning_rate=0.04`, `max_depth=2`, `min_samples_leaf=8`.
- **MLP:** скрытые слои `(32, 16)`, `alpha=0.01`, `learning_rate_init=0.003`, `early_stopping=True`, стандартизация признаков.

Для сравнения использована стратифицированная 5-fold кросс-валидация на обучающей части (`shuffle=True`, `random_state=42`), метрика выбора — средний ROC-AUC. Дополнительно проверено влияние `min_samples_leaf` у Random Forest (значения 1, 2, 3 и 5; 400 деревьев в каждом варианте). Тестовая выборка не использовалась для подбора параметров. Вероятности положительного класса получались через `predict_proba`; бинарные метки рассчитывались с порогом 0.5.

## Выбранная модель

Выбрана модель **Random Forest** с 500 деревьями, `max_features="sqrt"`, `min_samples_leaf=3` и `class_weight="balanced_subsample"`. Она выбрана по лучшему среднему ROC-AUC на кросс-валидации среди пяти сравниваемых семейств. Модель обучается в `Pipeline` вместе с медианной импутацией. Параметры фиксированы, `random_state` берётся из `EnsembleInput`.

На отложенной тестовой выборке результат выбранной модели:

- ROC-AUC: **0.8302**;
- Accuracy: **0.7750**;
- Precision: **0.8276**;
- Recall: **0.8571**;
- F1: **0.8421**.

Контрактная функция `run_ensemble_experiment` возвращает имя модели, вероятности положительного класса, бинарные предсказания и пять метрик. `test_target` используется только после `fit`, для итоговой оценки, но не для обучения или выбора признаков/параметров.

## Выводы и ограничения

Ансамбли деревьев показали более высокий ROC-AUC, чем MLP в данном эксперименте. Random Forest обеспечил наиболее высокий средний ROC-AUC в кросс-валидации среди сравниваемых базовых семейств. Gradient Boosting получил близкий и немного более высокий ROC-AUC на конкретной тестовой выборке, однако его средний CV ROC-AUC ниже; поэтому он не выбран по заранее заданному критерию. Это иллюстрирует, почему для выбора модели использовалась кросс-валидация, а не только тестовый результат.

HistGradientBoosting показал наибольшие Accuracy и F1 в этой тестовой выборке, но при выборе по ROC-AUC уступил Random Forest. MLP оказалась слабее остальных рассмотренных моделей; возможные причины — небольшой размер набора данных, кодирование категориальных признаков целыми числами и ограниченный набор проверенных архитектур/гиперпараметров.

Ограничения эксперимента: датасет содержит только 1 000 объектов; результаты зависят от конкретного разбиения; поиск параметров ограничен небольшим набором значений и не является исчерпывающим. ROC-AUC оценивает ранжирование вероятностей, а порог 0.5 не обязательно оптимален для прикладной стоимости ошибок. В рамках задания порог оставлен фиксированным для сопоставимости моделей.

## Воспроизводимость

- Python-библиотеки: `numpy`, `pandas`, `scikit-learn`.
- Разбиение: `test_size=0.20`, `random_state=42`, `stratify=y`.
- Кросс-валидация: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`.
- Случайное состояние моделей: `random_state=42`.
- Запуск:

```bash
python -m pip install numpy pandas scikit-learn
python run_experiments.py
```

Скрипт `run_experiments.py` заново выполняет сравнение, CV, тестовую оценку и записывает `experiment_results.json`.
